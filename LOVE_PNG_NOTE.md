# Love.png Image Required

## 📍 **Location Needed:**
Place your `love.png` image file in the `public/` folder:
```
public/love.png
```

## 🎨 **Image Specifications:**
- **Size**: 20x20 pixels (or similar small size)
- **Format**: PNG with transparency
- **Design**: Heart icon or love-themed icon
- **Color**: Pink/red theme preferred

## 🔧 **Usage:**
The love icon will be used for the **Relationship Consultant Mode** toggle button next to the upload button in the chat interface.

## 💡 **Alternative:**
If you don't have a love.png file, the current implementation uses an SVG heart icon as a fallback, so the feature will still work without the PNG file.
